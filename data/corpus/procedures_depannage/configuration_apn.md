# Configuration de l'APN (acces internet mobile)

Cette procedure s'applique lorsque le client ne parvient pas a se connecter a internet alors que son forfait data est actif et que le reseau mobile est capte.

## Parametres APN Teranga Telecom

Nom du point d'acces : internet.terangatelecom.sn
Nom d'utilisateur : (laisser vide)
Mot de passe : (laisser vide)
Type d'authentification : Aucune
Type d'APN : default,supl

## Configuration sur Android

Aller dans Parametres, puis Reseau mobile, puis Noms des points d'acces, puis appuyer sur le bouton "+" pour ajouter un nouveau point d'acces, saisir les parametres ci-dessus, enregistrer, puis selectionner ce nouveau point d'acces dans la liste.

## Configuration sur iPhone

Aller dans Reglages, puis Donnees cellulaires, puis Reseau de donnees cellulaires, et saisir les memes parametres dans la section APN Donnees cellulaires.

## Si le probleme persiste

Verifier que le mode avion n'est pas active, redemarrer l'appareil apres la configuration, et verifier que le forfait data n'est pas epuise en composant *144*4#. Si aucune de ces etapes ne resout le probleme, il s'agit probablement d'une panne reseau localisee : proposer une escalade vers un agent.
